# Changelog

## v1.0.0 — 2026-11-26

### English

- Added an 11-language interface, keyboard and gamepad controls, NPC challengers, and configurable Bot strategies.
- Added 22 playable Classic-candidate Card Carnival puzzles, World Tour, Shinra-8 tournament, Gold Saucer challenges and Shadowblood Queen.
- Improved match save recovery, result review, replay, and analysis flows.
- Added optional private local BGM playback controls. No music files are included.
- Continued the candidate local generation and import workflow for 145 Classic Art cards. Original FF7 assets and generated private card images are not included.

### 简体中文

- 新增 11 种界面语言、键盘与手柄操作、NPC 挑战者和可配置 Bot 策略。
- Card Carnival 扩展至 22 关 Classic 候选谜题，新增世界巡礼、游轮锦标赛、金碟挑战及暗影血女王。
- 改进对局存档恢复、结果查看、回放和分析流程。
- 新增可选的私人本地 BGM 播放控制；仓库不含音乐文件。
- 继续完善 145 张 Classic Art 卡牌的候选本地生成与导入流程。本仓库不含 FF7 原版素材和生成后的私人卡图。
