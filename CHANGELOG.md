# Changelog

## Unreleased

### English

- Added an 11-language interface, keyboard and gamepad controls, NPC challengers, and configurable Bot strategies.
- Added three playable Card Carnival puzzles; the full 22-puzzle set is not complete.
- Improved match save recovery, result review, replay, and analysis flows.
- Continued the candidate local generation and import workflow for 145 Classic Art cards. Original FF7 assets and generated private card images are not included.

- Card Carnival 新增 3 关可玩谜题；完整 22 关尚未完成。
- 改进对局存档恢复、结果查看、回放和分析流程。
