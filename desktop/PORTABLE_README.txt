Queen's Blood Classic — Windows x64 portable preview

1. Extract the complete ZIP to a folder you can write to.
2. Install Microsoft Edge WebView2 Runtime if Windows requests it.
3. Start QueensBloodClassic.exe.
4. To create private Classic Art, choose Generate Art Pack and select your own FF7 Original PC game-data folder. Original files stay on your computer; generated packs are stored in your user data folder.

This preview has not been tested in an independent clean Windows virtual machine. Card #134's J-Squad rule is unfinished, some complex rules remain candidates, and card art may be refined.

The package contains no FF7 game archives, extracted game assets, or generated/private card art. See licenses/ and source.zip.
