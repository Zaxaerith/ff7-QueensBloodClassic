# Queen's Blood Classic v0.8.0-rc.2 — Source-only Preview

## English

This is an unofficial Final Fantasy VII fan-made project. It is not affiliated with or endorsed by Square Enix.

This is a **Source-only Preview**. No Windows binary has passed acceptance, and this release contains no EXE or Windows package. It contains project source only, distributed through GitHub's automatically generated source archives. The source includes candidate local generation routes for all 145 Classic Art cards, but no FF7 Original game archives, extracted game models or textures, private Art Pack, or generated private card images. Players must provide their own lawfully obtained FF7 Original PC game data on their device and generate/import any private Art Pack locally.

The Windows GUI has not yet been manually accepted. A Windows binary release is not part of this preview; independent clean Windows virtual-machine compatibility testing has not been completed. Microsoft Edge WebView2 Runtime is required for a future desktop build.

The game source includes a 3×5 board, configurable Bot, deck building, mulligan, automatic PASS, match presentation and scoring, saved records, replays, and strategy analysis. The 145-card art routes are candidate local-generation implementations. Known limits: card #134 has an executable candidate J-Squad rule whose accuracy to the original game has not been fully verified; some complex rules remain candidates; and card art can still be refined.

Source is GPL-3.0-only. See `LICENSE` and `THIRD_PARTY_NOTICES.md`. GPL applies to this project's source; it does not provide rights to third-party game assets or characters.
