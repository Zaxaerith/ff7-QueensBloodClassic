# Queen's Blood Classic v0.8.0-rc.2 Preview

## English

This is an unofficial Final Fantasy VII fan-made project. It is not affiliated with or endorsed by Square Enix.

The Windows x64 portable package was built by GitHub Actions from the public source commit identified in `build-manifest.json`. It contains no FF7 Original game archives, extracted game models or textures, private Art Pack, or generated private card images. Players must provide their own lawfully obtained FF7 Original PC game data on their device. The complete 145-card Classic Art set can be generated locally and imported as a private Art Pack.

The Windows GUI candidate was manually checked before this preview. It has not been independently tested in a clean Windows virtual machine. Microsoft Edge WebView2 Runtime is required.

The game includes a 3×5 board, configurable Bot, deck building, mulligan, automatic PASS, match presentation and scoring, saved records, replays, and strategy analysis. Known limits: card #134's J-Squad rule is unfinished; some complex rules remain candidates; and card art can still be refined.

Source is GPL-3.0-only. See `LICENSE` and `THIRD_PARTY_NOTICES.md`. GPL applies to this project's source; it does not provide rights to third-party game assets or characters.
