# Queen's Blood Classic v0.9.0-rc.1 — Source-only Preview

## English

This is an unofficial Final Fantasy VII fan project and is not affiliated with or endorsed by Square Enix. This release is a **Source-only Preview** distributed through GitHub's source archives. It contains no Windows executable or accepted Windows binary.

### M7

- Protects the current save if creating or restarting a match cannot write the replacement save.
- After a match ends, players can return home, reopen the latest result, and rematch without archiving the same match twice.
- The maintainer accepted a local private art baseline for all 145 cards. Its derived images and private Art Pack are excluded from this repository and release. The public generator is not claimed to reproduce every refinement in the private baseline.
- An internal 145-card rule-evidence ledger has been prepared, but it does not establish every rule through original-game evidence. #066 Two Face feedback behavior remains to be verified. #134 has an executable J-Squad candidate rule, but its derived-card strengths and accuracy to the original game are not fully verified.

### Play and generate art

For the Web game, install Node.js 22.12 or newer, run `npm ci` and `npm run dev`, and open the local Vite URL. No Windows EXE is included. To generate a private Art Pack, provide your own lawfully obtained FF7 Original PC game data and follow [the local generator guide](../LOCAL_ART_GENERATOR.md). Original game archives, extracted models or textures, and generated/private card images are not included in this release. Keep source game files and generated art on your own device.

### Limits and license

Some complex rules remain candidates, and card art can still be refined. Windows GUI acceptance and independent clean-Windows-VM compatibility testing are incomplete. ### M7 更新

- 创建新对局或重开时，如果替换存档写入失败，会保护当前存档。
- 对局结束后可返回主页、重新查看最近一局结果并再战，不会重复归档同一局。
- 维护者已接受本地 145 张卡的私人美术基线；派生卡图和私人 Art Pack 不包含在本仓库或本次发行中。公开生成器不保证复现私人基线的全部精修细节。
- 内部已整理 145 张卡的规则证据台账，但不代表所有规则均由原作实证。#066 Two Face 的循环反馈仍待核验。#134 已有可执行的 J-Squad 候选规则，但衍生牌力量及其与原作的一致性尚未完全核实。

### 游戏与本地生成卡图

浏览器运行方式：安装 Node.js 22.12 或更新版本，执行 `npm ci`、`npm run dev`，然后打开 Vite 显示的本机地址。本次不含 Windows EXE。生成私人 Art Pack 时，玩家需自行提供合法取得的 FF7 Original PC 游戏资源，并按[本地生成指南](../LOCAL_ART_GENERATOR.md)操作。本次不包含原版游戏档案、提取模型或纹理，也不包含生成后的私人卡图；请将原始资源和生成卡图保留在自己的设备上。
