# Queen’s Blood Classic v1.0.0

Unofficial fan project. Play World Tour, 22 Classic-candidate Card Carnival puzzles, the Shinra-8 tournament, Gold Saucer challenges, and the Shadowblood Queen. Includes 11 languages and Windows desktop resource management. Card art and local music can be generated or mounted from resources you provide; no original game assets or private audio are distributed.

非官方同人项目。体验世界巡礼、22 关 Classic 候选卡牌嘉年华、游轮锦标赛、金碟挑战和暗影血女王。支持 11 种语言及 Windows 桌面资源管理。玩家可使用自行提供的资源生成或挂载卡图与本地音乐；发行包不含原版游戏素材或私人音频。
